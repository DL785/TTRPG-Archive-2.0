# Игровой архив — инструменты мастера НРИ

Готовый статический сайт для GitHub Pages. Вкладки «Библиотека» и «Доска» включены в один index.html. Сервер, база на хостинге, вход в аккаунт и установка зависимостей для публикации не нужны.

## Загрузка на GitHub

1. Распакуйте ZIP на компьютере.
2. Откройте нужный репозиторий GitHub → Add file → Upload files.
3. Загрузите содержимое распакованной папки в корень репозитория. Файл index.html должен лежать сразу в корне, а не внутри ещё одной папки. Загрузите также archive.json и .nojekyll. Остальные файлы — исходники и инструкция, их тоже можно загрузить.
4. Подтвердите загрузку: Commit changes.
5. Откройте Settings → Pages. В Source выберите Deploy from a branch, ветку main (или вашу основную ветку), папку /(root), нажмите Save.
6. Дождитесь публикации. Адрес сайта появится в Settings → Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Если обновляете прежний репозиторий, замените index.html. СВОЙ archive.json сохраняйте: файл из этого комплекта содержит пустую библиотеку для первого запуска.

## Что входит

- index.html — готовый сайт: библиотека, журнал, календарь, хроника, PNG-инфографика, доска, сцены, маркер, текст, изображения, PDF и кубы.
- archive.json — пустая начальная библиотека. Можно заменить экспортом своей библиотеки.
- .nojekyll — отключение обработки сайта Jekyll.
- src/, board/, build.mjs, package.json — редактируемые исходники и сборка для дальнейших изменений.
- THIRD_PARTY_NOTICES.txt — сведения о сторонних библиотеках.

## Данные и перенос

Изменения сохраняются в браузере, а не в файлах репозитория. Для переноса на другой адрес сайта или устройство экспортируйте данные на старом сайте и импортируйте на новом.

Библиотека: меню «Данные» внизу слева → Экспорт JSON / Импорт JSON.
Доска: кнопки «Экспорт» / «Импорт» сверху справа. Экспорт включает сцены, изображения, PDF и историю бросков.

Экспорт библиотеки и экспорт доски — два разных файла. Импорт каждого заменяет данные соответствующего раздела после подтверждения. Перед переносом сохраните оба экспорта.

На прежнем адресе GitHub Pages данные того же браузера сохраняются после замены index.html. Если адрес изменился, используйте экспорт и импорт. Автоматической синхронизации между устройствами и совместной игры в этой версии нет.

archive.json загружается при первом запуске, когда в браузере ещё нет локальной библиотеки. Кнопка «Загрузить с GitHub» позволяет вручную заменить библиотеку данными из этого файла после подтверждения.

## Открытие без хостинга

index.html можно открыть на компьютере двойным щелчком. В этом режиме начальный archive.json нужно импортировать вручную. Возможность локального сохранения зависит от настроек браузера; для постоянной работы рекомендуется адрес GitHub Pages.

## Пересборка после изменения исходников

Для обычной публикации ничего собирать не нужно: index.html уже готов.
Для разработки установите Node.js, затем в этой папке выполните:

```sh
npm install
npm run build
```

После сборки загрузите обновлённый index.html на GitHub. Изменения board/index.html, board/style.css и board/app.js попадут во встроенную доску при пересборке.
